
# Two-Factor Authentication

A Qt-based Two-Factor Authentication project.

## Project Description

This project is a simple Two-Factor Authentication (2FA) system developed using Qt and C++. It adds an extra layer of security by using a username, password, and OTP for user verification.

## Features

- Username input
- Password input
- OTP verification
- Login/verification system
- Simple and user-friendly GUI

## Technologies Used

- C++
- Qt
- CMake

## How to Run

1. Download or clone this repository.
2. Open the project in Qt Creator.
3. Open the `CMakeLists.txt` file.
4. Configure and build the project.
5. Run the application.

## Project Files

- `main.cpp` - Main application file
- `mainwindow.cpp` - Main window implementation
- `mainwindow.h` - Main window header file
- `mainwindow.ui` - User interface design
- `CMakeLists.txt` - CMake project configuration
